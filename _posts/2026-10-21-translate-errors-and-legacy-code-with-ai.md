大家好，我是Zack。

先说两个场景，看你中过哪个。

一个是学编程：终端里蹦出十行红色报错，一行都看不懂，谷歌搜半天，搜出来的答案还是看不懂。

另一个是接手别人的代码：一段老逻辑没人写注释，变量名叫 wsAdjust，你盯着它十分钟，不知道敢不敢动。

这两个场景过去是同一道坎：看不懂机器话，就只能硬扛。今天讲的做法能让这道坎消失——看不懂的，整段复制，扔给 AI 翻译。报错一段 14 秒出人话，一段 COBOL 老代码 15 秒翻完。命令直接可抄。

**我原来的做法，以及卡在哪**

先说报错。以前我带新手的流程是：把报错里最后一个单词复制下来，粘进搜索引擎，翻前三个结果，对答案。

卡点很明显。Python 的报错是分层的，最后一行是结论，中间八行是调用路径。新手不知道该搜哪行，经常拿第一行去搜，搜出来一堆不相关的东西。一条报错这么折腾，五分钟没了；一个下午撞五条，人就劝退了。

再说老代码。我做过几年云原生，接手过别人的服务，那些代码已经是英文的了，都嫌费劲。真正的老系统比这狠得多：全世界的银行系统还跑在 COBOL 上，那是一门 1959 年出生的语言，语法跟现在所有主流语言都不像，会写的人比系统先退休。

以前遇到这种东西只有两条路：要么花几周学语言，要么花大价钱找顾问。普通人的项目两条都用不起，所以那部分代码就烂在那里，没人敢碰。

**现在的做法：整段外包给 AI**

现在这两件事我都换了一个动作：复制，粘贴，让它讲人话。

我在终端里装了 Claude Code（装法上一篇写过，一条 curl 命令的事），它有个 `claude -p` 模式，意思是「回答完这个问题就退出」，不进交互界面，适合一次性翻译。

第一步，翻译报错。先造一个真实报错，一个类型混用的经典款：

```python
def add(a, b):
    return a + b

print(add("1", 2))
```

跑一下，报错整段是十行，从 Traceback 开始到 TypeError 结束。以前的新手看到这个就关窗口了。

现在的动作是把这十行原样塞给 AI，一条命令：

```bash
claude -p "把这段报错用人话解释，一句话说错在哪，
一句话说怎么改，不要展开：
（这里粘贴完整的报错原文）"
```

它回我的原话是：错在把字符串 "1" 和数字 2 直接相加，Python 不允许 str + int；改成 add(1, 2) 或 add("1", "2")，让两个参数类型一致。

我掐了表：**13.8 秒**。以前谷歌搜索加比对答案的流程是五分钟起步，现在十几秒就出答案，而且答案是针对你这段报错的，不是「可能适合你的情况」。

第二步，翻译老代码。我写了一段 11 行的 COBOL 样例（演示用，逻辑取自最常见的「账户余额加调整额」场景），整段丢进去，要求是「逐段用人话讲它是干什么的，最后用 Python 等价改写」：

```bash
claude -p "这段 COBOL 逐段用人话讲它是干什么的，
最后用 Python 等价改写。要求简洁：
（这里粘贴代码原文）"
```

**14.7 秒**，回的内容分三层：先逐段翻译——这段是定义两个带小数位的账户变量，那段是把调整额加到余额上再打印；然后给了 Python 等价写法，连「金额要用 Decimal 而不是浮点」这种精度坑都处理了。

更值的是第三层：它主动指出这两个变量没赋初值，COBOL 里默认按 0 算，所以程序会输出 BALANCE: 0。

这就是「外包读」和「自己查词典」的差别。词典只告诉你每个词什么意思，外包给 AI 它连坑都替你踩出来了。

第三步，算一笔账。有人会说：AI 是不错，但天天调用，费用扛得住吗？

一瓶水的钱，买一次「十行报错变人话 + 老代码逐段翻译」。这类翻译任务的调用量再大，一个月也就几十块，比你请人看代码便宜两个数量级。

**两条可以迁移的原则**

第一，所有「看不懂的机器话」都是翻译任务。报错、日志、老代码、别人写的正则、一段 YAML 配置，全都适用同一个动作：整段复制，要求讲人话。要点是「整段」——只贴最后一行，AI 就丢了调用路径这些上下文，答案质量直接掉一档。

第二，外包读，不外包判断。AI 翻译完，改不改、怎么改，决定权在你手里。它说的是「类型不一致」，你至少要知道字符串和数字是两种类型，才能看懂它的方案。让 AI 当翻译，别让它替你签字。

**说点局限**

一是长代码别一口气全贴。上千行的文件先只贴看不懂的那一段，上下文给足（「这是一个计费脚本里的函数」），翻译质量比整坨扔进去高。

二是它可能翻错冷门语言。COBOL 这类训练语料少的语言，遇到冷门方言时细节可能出错，要改的逻辑找第二来源核对一遍，别拿翻译结果直接上线。

三是数据敏感的代码贴之前先脱敏，账号、密钥、客户数据换掉再发。

这三条都不影响日常用。你下次再被报错卡住，先别关窗口，复制整段，贴给它，掐个表看看用了几秒。
