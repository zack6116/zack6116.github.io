大家好，我是Zack。

后台隔三差五收到同一类私信：想学编程，装环境装了三天，卡在 command not found，人先劝退了。

今天这篇就讲一件事：这一步现在可以整个跳过。

不用装 Python，不用配环境变量，一条命令，十分钟内跑通你的第一个程序。命令我贴在下面，直接抄。

## 我当年是怎么被环境劝退的

2016 年我辞了职，回武汉，自学 Linux 和 Python。

那时候没有捷径。先去官网下安装包，再配 PATH。PATH 是系统找命令的路径清单，配错一个符号，终端就回你一句 command not found。

装 Python 还要先搞明白：系统里已经有一个旧版本了，两个版本怎么共存。装完 Python 还要装 pip，pip 是装第三方库的工具。然后写第一行代码要选编辑器，编辑器还要配插件。

还没写第一行代码，一天就没了。

更狠的是 node。我自己这台 Mac 上现在就同时存在两份 node，brew 装的一份，工具自己管的一份，命令行跑的是哪个全看 PATH 里谁排前面。

这种问题老手都要查半天，新手直接死在这。

所以我想先说一句：卡在装环境不是你不行，是这一步本来就不该让人干。装环境是机器擅长的事，现在机器自己能干了。

## 现在的做法：一条命令

现在带人上手，我只要求一件事：打开终端（Mac 上叫「终端」，Windows 上叫 PowerShell），粘贴这条命令：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows 用户换这条：

```powershell
irm https://claude.ai/install.ps1 | iex
```

这是 Claude Code 的官方安装器。Claude Code 是 Anthropic 出的编程工具，跑在终端里：你说需求，它写代码、跑命令、自己修报错。

装完验证一下：

```bash
claude --version
```

我机器上刚跑的输出是 `2.1.302 (Claude Code)`。能看到版本号就是装好了。

全程没碰 Node.js，没碰 PATH。

注意一点：这个安装器是自带独立二进制的，意思是它把要用的东西全打成了一个文件。所以你不需要先装 Node.js，也不需要 Python。

网上大量教程还让你「先装 Node 18，再 npm install -g」，那是老路。官方文档现在写的就是上面这条 curl 命令，一步到位。

## 第二步：进文件夹，说需求

随便找个位置建个空文件夹，进去：

```bash
mkdir ~/my-first-app && cd ~/my-first-app
```

然后跑：

```bash
claude
```

第一次跑会让你在浏览器里登录账号，登录完回到终端，直接用人话打需求。

你可以从这种需求开始：

「帮我做一个记账小网页，能输入金额和备注，列表显示，数据存在本地。」

它会自己建文件、自己写代码、自己起服务，最后给你一个能打开的页面。中间要装什么依赖、要改什么配置，它自己处理，处理不了的会停下来问你。

以前这三天的活：装环境、配路径、查报错，现在是它干活，你看结果。

## 前后对比

| | 以前自己装环境 | 现在 |
|---|---|---|
| 要装的软件 | Python + 编辑器 + 插件 + 依赖，4 层 | 1 条命令 |
| 要懂的名词 | PATH、版本共存、虚拟环境 | 会打字就行 |
| 跑通第一个程序 | 1-3 天，多数人没跑通 | 10 分钟左右 |
| 报错谁处理 | 自己搜教程碰运气 | 它自己修 |

两点局限也说实话：

一，claude.ai 在国内网络直连经常打不开，安装这一步就需要网络能正常访问它，这是目前最大的门槛。

二，Claude Code 要登录 Anthropic 账号，订阅是付费的。想白嫖的先别急着上，等想清楚要做的东西值不值这个钱。

环境知识也不是永远不用懂。等你的项目要上线、要给别人用，端口、域名、服务器这些还是躲不开。但那是你做出东西之后的事，不该是第一道门槛。

## 两条通用原则

一，能交给机器的安装活，别自己动手。装环境、配路径、处理依赖冲突，机器干得又快又不出错。你的时间该花在「做什么」上，不是「装上」上。

二，教程会过期，命令要现查。搜到的攻略可能停在三步前的老路上，照着走不是错，是慢。工具的官方文档永远比三年前的攻略新。
